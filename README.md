# Koreader 微信读书 青春版

## 仅供学习交流，请于下载24小时后删除

## 特点

<img width="644" height="996" alt="image" src="https://github.com/user-attachments/assets/89b43352-a39a-4cda-bec7-d46d6f62506a" />


* 轻、快、稳
* 模拟Kindle网页版，非爬虫
* 只支持在线联网阅读，不支持离线下载、缓存（未来也不会支持）
* 支持个人读书数据统计（使用微信读书官方SKILL）
* 支持书籍搜索（使用微信读书官方SKILL）
* 支持进度同步
* 支持自定义首页布局
* 支持划线，不支持笔记
* 查看其他用户的划线和想法（使用微信读书官方SKILL）
* 可与其他三方桌面/美化/插件等共存（如遇兼容性问题请在issue区提供crash.log）

## 温馨提示

安卓版Koreader不支持使用，后续也不会维护安卓版，理由是安卓版可以安装官方微信读书apk，不需要使用koreader微信读书这种脱裤子穿麻袋放屁的方式。

## 安装方式

和其他所有 Koreader 插件的安装方式一样，不再赘述

## 入口

安装后，启动Koreader，你的Koreader书籍列表中的第一本书会变成【微信读书】，点击即进入
