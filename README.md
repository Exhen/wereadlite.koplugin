# Koreader 微信读书 青春版

## 仅供学习交流，请于下载24小时后删除

## 特点

* 轻、快、稳
* 模拟Kindle网页版，非爬虫
* 只支持在线联网阅读，不支持离线下载、缓存（未来也不会支持）
* 支持个人读书数据统计（使用微信读书官方SKILL）
* 支持书籍搜索（使用微信读书官方SKILL）
* 支持进度同步
* 支持自定义首页布局
* 支持划线、笔记（待开发）
* 不支持查看其他用户的划线和想法（除非Kindle网页版改版，否则未来也不会支持）


## 安装方式

和其他所有 Koreader 插件的安装方式一样，不再赘述

## 入口

安装后，启动Koreader，你的Koreader书籍列表中的第一本书会变成【微信读书】
